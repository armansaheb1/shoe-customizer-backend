# Shoe Customizer Backend

Backend service for a custom shoe design and material management platform built with Django and Django REST Framework.

## Overview

This platform allows management of shoe models, materials, patterns, and customization options through a REST API architecture.

The system was developed as a real-world freelance project and supports product customization workflows and administrative management.

## Features

- Shoe model management
- Material management
- Pattern management
- Product customization logic
- User authentication
- Administrative dashboard
- REST API architecture
- Product catalog management

## Tech Stack

### Backend

- Python
- Django
- Django REST Framework
- PostgreSQL

Frontend Application

Django REST API
